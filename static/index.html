Đăng nhập Telegram

Cách lấy API ID và API Hash
  1. Mở my.telegram.org/apps và đăng nhập bằng số Telegram.
  2. Chọn hoặc tạo app mới, có thể điền tên bất kỳ.
  3. Sao chép api_id vào ô API ID và api_hash vào ô API Hash bên dưới.
